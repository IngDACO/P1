PASO 3 — OPTIMIZACIÓN
optimizer.py — Grid Search RL × FB (paso 0.5 mm)
🔄
Rango de búsqueda
RL ∈ [−MAX_OFF_RL, +MAX_OFF_RL]  |  FB ∈ [−MAX_OFF_FB, +FB_MAX_BACK]
Constantes por RL: wall_active · wall_stop_idx · wall_check_col · wall_lim_val · toward_wall
▼
🚫
Paso 1 — Límites físicos de RL
|RL| > LIMIT_R (o LIMIT_L) → SKIP [physical_rl]
▼
🚫
Paso 1b — Límite físico de FB
FB > FB_MAX_BACK → SKIP [physical_fb]
▼
🏗
Paso 2 — FB extra por pared limitante
Si wall_active AND OR/OL en wall_stop > LIMIT AND FS > TSW:
  extra = FS − TSW  |  fb_applied = min(fb + extra, fb_max_back)
  fb_extra_applied = True ← cabina evade físicamente la pared
▼
🚪
Paso 2b — Apertura de cabina (★ v25)
Si fb_extra_applied AND |RL| > FRAME → SKIP [frame_opening]
La apertura de cabina quedaría tapada por la pared limitante
▼
🔢
Paso 3 — Contar violaciones
Por cada celda (nivel, col):
  • ctrl_applies? → eff_lim = LIMIT − 70
  • Si fb_extra_applied AND nivel=wall_stop AND col=wall_check_col → saltar (evadida)
  • OR/OL: v > eff_lim → OFF  |  WR/WL/FR/FL: v < eff_lim → OFF
▼
🧱
Paso 4 — Hard SKIP por pared (sin evasión)
Si wall_active AND NOT fb_extra_applied AND OR/OL > LIMIT → SKIP [wall]
▼
✅
Registro VALID → Actualizar mejor
Objetivo: min total_off  |  Tiebreaker: min(|rl| + |fb_applied|)
Salida: best · all_solutions · step_log
PASO 4 — BSR vs BS
📏 bs_logic.py — find_bs_step()
BSR ≥ BS
No se requiere ajuste
BSR < BS → dif = BS − BSR
Barre 3 rangos (paso 0.5 mm):
[0,ZB] → [ZB, ZB+OB] → [ZB+OB, 1000]
dif −= val; dif ≤ 0 → retorna step

REFERENCIA — GEOMETRÍA FÍSICA

Eje Lateral (izquierda ↔ derecha)

┌──────────────────────────────────┐ │ SF1 │◄── BKS + 2×RAIL ──►│ SF2 │ ← BS │ │ CABIN BLOCK │ │ │ WL │ │ WR │ │ OL │ [apert. puertas] [ap]│ OR │ └──────────────────────────────────┘
BT = apertura de puertas (NO = ancho cabina)
WR/WL < LIMIT → violación lateral
OR/OL > LIMIT → requiere corte · max RL hacia pared = FRAME
BS = SF1 + BKS + 2×RAIL + SF2

Eje Frontal (adelante ↔ atrás)

┌────────────────────────────────┐ │ FS │ TKSW │ TL │ ← TS │ front │ rail │ cabin body │ │ │● │ │ └────────────────────────────────┘ ● = centro del riel
FR/FL = dist. pared frontal → centro riel
FR/FL < LIMIT → violación frontal
FB_MAX_BACK = FS − TSW (máx desplaz. atrás)
TL = TS − BC_CALC (prof. bloque cabina)
